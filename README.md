# Poster Pro - ناشر برو

تطبيق Android متقدم لنشر تلقائي على مجموعات Facebook بدعم حسابات متعددة وحملات مخصصة.

## الميزات الرئيسية

### 1. إدارة الحسابات (الشاشة الأولى)
- تسجيل دخول آمن إلى Facebook عبر WebView
- دعم الحسابات الشخصية والصفحات
- عرض حالة الاتصال (متصل/غير متصل)
- حفظ آمن للبيانات الحساسة باستخدام FlutterSecureStorage
- حذف الحسابات بسهولة

### 2. إنشاء حملات (الشاشة الثانية)
- إنشاء حملات نشر مخصصة
- دعم النصوص بالعربية (RTL)
- رفع صور (1-3 صور)
- إدخال روابط مجموعات متعددة
- اختيار حسابات متعددة للنشر
- تعيين تأخير زمني بين المنشورات (15-45 ثانية قابلة للتخصيص)
- حفظ الحملات للاستخدام لاحقاً

### 3. لوحة النشر المباشر (الشاشة الثالثة)
- عرض تقدم النشر بشكل مرئي
- عدادات حية (نجح/فشل/المتبقي)
- سجل نشر مباشر ملون
- إمكانية إيقاف مؤقت واستئناف النشر
- إيقاف كامل للعملية
- تصدير التقارير بصيغة نصية

### 4. الإعدادات (الشاشة الرابعة)
- قائمة كلمات عشوائية للـ [RAND]
- تفعيل/تعطيل إضافة اسم الجروب تلقائياً
- تفعيل/تعطيل إضافة إيموجي عشوائي
- خيار تخطي الجروبات الفاشلة
- اختيار سرعة النشر (بطيء/عادي/سريع)
- مسح جميع الحسابات
- مسح سجل النشر
- عرض إصدار التطبيق

## التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone <repository-url>
cd poster_pro_flutter
```

### 2. تثبيت الحزم
```bash
flutter pub get
```

### 3. التشغيل على محاكي أو جهاز
```bash
flutter run
```

### 4. بناء APK
```bash
flutter build apk --release
```

راجع `BUILD_INSTRUCTIONS.md` للتفاصيل الكاملة.

## استكشاف الأخطاء الشائعة

### مشكلة: "Android SDK not found"
**الحل**: قم بتعيين متغير ANDROID_HOME
```bash
export ANDROID_HOME=/path/to/android/sdk
```

### مشكلة: "WebView not responding"
**الحل**: تأكد من تحديث WebView على الجهاز من Google Play Store

### مشكلة: "Permission denied"
**الحل**: تأكد من منح الأذونات المطلوبة في إعدادات الجهاز
